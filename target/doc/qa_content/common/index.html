Shared helpers for Quake model and sprite formats.

Donor provenance: src/formats/q12-model/common.ts (failure, counting, version, vector, sync/group, interval, timed-frame, packed-vertex, and bounds helpers). All format parsers report [qa_core::binary::BinaryError], exactly like the donor.
