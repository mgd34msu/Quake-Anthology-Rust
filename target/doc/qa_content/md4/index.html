Quake III skeletal model (MD4 v1) parser and skinning.

Donor provenance: src/formats/q3-model/md4.ts (loading from qfiles.h and tr_model.c, bone indexing from tr_animation.c, skinning from RB_SurfaceAnim). The dot-product order matches [qa_core::math::dot3], which this port reuses.
